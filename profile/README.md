# Collegeville

Learning and working as computing advances. Collegeville applies the scientific method to how we learn, build, and trust technical work as computing changes: papers, tools, skills, and games, grown out of decades of teaching and scientific software work. Visit **[collegeville.github.io](https://collegeville.github.io/)**.

## The Fables games

Short daily puzzles, each a small gym for a skill that matters more as AI changes our work. Most keep sharp the skills AI now does quickly, so we keep the judgment to check its work. UDXFables trains user and developer experience, which grows in importance as AI automates the mechanics of building software. EarFables and ClapFables train the musician's ear and eye, so people can check the music AI now writes and transcribes.

| Game | What it trains | Status |
| --- | --- | --- |
| [DataFables](https://collegeville.github.io/DataFables/) | A daily data-cleaning puzzle: find what's wrong with the table, or decide that nothing is. | Live |
| [CodeFables](https://collegeville.github.io/CodeFables/) | Read short Python snippets, predict what they do, and spot what's wrong. | Live |
| [ScaleFables](https://collegeville.github.io/ScaleFables/) | How does it grow, and how does it speed up? Build the instinct for how code scales. | Live |
| [TestFables](https://collegeville.github.io/TestFables/) | When can you trust a green checkmark? What would this test catch, and what would slip through? | Live |
| [UDXFables](https://collegeville.github.io/UDXFables/) | Who is it for, and what do they need right now? User and developer experience for the people and agents who build and use software. | Live |
| [EarFables](https://collegeville.github.io/EarFables/) | Hear the tune, find the score: a short melody plays, and you pick the score that matches. | Live |
| [ClapFables](https://collegeville.github.io/ClapFables/) | Hear the rhythm, find the score: two bars are clapped, and you pick the written rhythm that matches. | Live |
