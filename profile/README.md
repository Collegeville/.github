# Collegeville

Learning and working as computing advances. Collegeville applies the scientific method to how we learn, build, and trust technical work as computing changes: papers, tools, skills, and games, grown out of decades of teaching and scientific software work. Visit **[collegeville.github.io](https://collegeville.github.io/)**.

## The Fables games

Short daily puzzles, each a small gym for a skill that AI tools now do quickly, so we keep the judgment to check their work.

| Game | What it trains | Status |
| --- | --- | --- |
| [DataFables](https://collegeville.github.io/DataFables/) | A daily data-cleaning puzzle: find what's wrong with the table, or decide that nothing is. | Live |

More are on the way: code, scaling, testing, and user and developer experience.
